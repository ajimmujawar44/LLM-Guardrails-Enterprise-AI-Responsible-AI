## 📌 Project Overview

Large Language Models (LLMs) are powerful, but they can sometimes generate unsafe, harmful, sensitive, or inappropriate responses.

This project demonstrates how **LLM Guardrails** can be used to make AI applications safer and more reliable.

The system acts as a security layer between the user and the Large Language Model.

### 🔄 Basic Flow

```text
User Prompt
     ↓
Input Guardrails
     ↓
Security & Safety Checks
     ↓
Google Gemini LLM
     ↓
Output Guardrails
     ↓
Response Validation
     ↓
Safe Response
